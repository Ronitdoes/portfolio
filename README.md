# Developer Portfolio

A premium developer portfolio website built using Next.js App Router, GSAP, and Tailwind CSS.

## Key Features

- **Horizontal Curtain Transition**: Smooth, high-energy horizontal page wipes built with `next-transition-router` and `GSAP`.
- **Preloader & Intro Skip**: Dynamic intro loading animation that runs on first entry, and is automatically skipped on subsequent routing navigations.
- **Split Text Anim**: Custom character split animation for page names on the transition curtain.
- **Interactive Canvas Hands**: Interactive ASCII canvas hand movements tracking the cursor.
- **Modern Design System**: Clean typography utilizing Absans and Outfit fonts with a sleek dark theme.

## Tech Stack

- **Core Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Animation Framework**: [GSAP](https://greensock.com/gsap/) with `@gsap/react`
- **Routing & Transitions**: [`next-transition-router`](https://github.com/ismamz/next-transition-router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
